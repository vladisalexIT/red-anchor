# Архитектура проекта «Красный якорь»

## Назначение

Многостраничная frontend-вёрстка коммерческого сайта.

## Технологии

- Vite
- Vituum
- TypeScript
- Nunjucks
- SCSS

## Основные принципы

- Проект является многостраничным сайтом, не SPA.
- Каждая страница находится в `src/pages`.
- Общий HTML находится в `src/templates`.
- Повторяющиеся элементы реализуются через Nunjucks includes и macros.
- Стили разделяются на настройки, базовые правила, раскладку, компоненты и страницы.
- Интерактивность реализуется независимыми TypeScript-модулями.
- Модули не должны завершаться ошибкой, если соответствующего компонента нет на странице.
- Серверные сценарии заменяются демонстрационными frontend-адаптерами.
- `fluid()` используется для плавных размеров.
- Медиазапросы используются для структурных изменений интерфейса.

## Маршруты

Страница `src/pages/example/index.njk` собирается как `/example/`.

## Именование

- Каталоги и файлы: `kebab-case`.
- TypeScript-функции и переменные: `camelCase`.
- Классы компонентов: BEM-подобная схема.
- JavaScript-хуки: атрибуты `data-*`, а не CSS-классы.

## Контроль качества

Перед коммитом выполняется:

`npm run check`
